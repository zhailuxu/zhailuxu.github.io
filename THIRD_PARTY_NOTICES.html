三、外部或本地运行服务

  • GoatCounter：托管统计服务；当前对合理的公开网站流量免费，具体以其最新使用条款为准。
  • Ollama：本机推理程序采用 MIT 许可证；通过 Ollama 使用的每个模型都有独立许可证，部署前须逐个核对。
  • EasyOCR：采用 Apache License 2.0；模型文件及其依赖应随实际部署环境一并核对。
  • Claude Code：beads.html 的可选本地代理会调用用户已登录的 Claude Code，可能消耗订阅额度或产生 API 费用。
  • Web Speech API、Web Audio API、Canvas、SVG：浏览器原生能力，不是按调用计费的第三方素材服务。

四、系统字体与 Emoji

页面 CSS 会按名称调用 Comic Sans MS、华文圆体、微软雅黑、PingFang SC 等系统字体。本站不分发这些字体文件，实际显示由访问者设备已安装字体及其系统许可决定。页面中的 Emoji 以 Unicode 文本保存，没有随项目分发第三方 Emoji 图片集。
